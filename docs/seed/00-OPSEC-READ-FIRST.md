# Private-info safety — READ FIRST

This pack is a **clean start** for a new Grok Build conversation.
It deliberately contains **no prior chat history**, no private family material,
and no operator-surface inventory.

## Allowed in new chats
- Public system purpose (what AOS / Hive Brain is)
- **Someone else can continue** + **honest history** (not popularity) as the fixed rules
- Public products at principle level (civic tools, learning path)
- Honesty labels: Supported / Unproven / Disputed · human decision
- Build requests for public-safe tools
- Interactive Hive demo: 20 shapes · 5 rooms · shorter/fuller stories · node inspect

## Forbidden to re-introduce from memory or old threads
- Named persons, family history, or re-identifying primary-source dumps
- Operator runbooks, port maps, gate inventories, internal path maps
- Secrets, credentials, municipality product samples as fixtures
- Treating multi-tool agreement as automatic truth
- Shipping by token spend or popularity metrics

## How to start clean
1. Open a **new** Grok Build conversation (do not continue the old thread).
2. Attach or paste `01-NEW-CHAT-SEED.md` as the first message.
3. Do **not** paste prior chat exports into the new thread.
4. Keep this pack as the only prior context document.
