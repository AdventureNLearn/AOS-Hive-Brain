# OPSEC — Public ship rules (AOS Hive Brain)

**Class:** PUBLIC system brief + interactive demo  
**North star:** Replication · Fidelity (not engagement)

This repository is intentionally **OPSEC-clean**. It is safe to fork, demo, and build on.

## Allowed

- Public system purpose (what AOS / Hive Brain is)
- Replication + fidelity as the success criteria
- Public products at principle level (civic suite, educational tutor)
- Integrity language: Supported / Unproven / Disputed · human final call
- Demo-quality public tools and reasoning visualizations

## Forbidden in this repository

| Category | Examples |
| --- | --- |
| Private history | Named persons, family material, re-identifying biography |
| Operator surface | Runbooks, port maps, gate inventories, internal path maps |
| Secrets | OAuth secrets, API keys, tokens, database credentials |
| Engagement theater | Shipping by likes, dwell, virality, or token spend |
| Auto-truth | Treating multi-model agreement as automatic truth |
| Dirty fixtures | Municipality samples, private research dumps |

## Seed pack discipline

The clean seed lives in [`docs/seed/`](./seed/) and is also downloadable from the app UI.

1. Open a **new** build conversation (do not continue old private threads).
2. Paste only `01-NEW-CHAT-SEED.md` as message 1.
3. Do **not** paste email envelopes, personal addresses, or prior chat exports.
4. Inventory in the pack must match files actually shipped.

## Integrity kernel

- Supported / Unproven / Disputed
- Evidence / Inference / Assumption labeled
- Primary records beat commentary
- Multi-model agreement ≠ automatic truth
- **Human final call** is non-negotiable
- Prefer honest incomplete state over confident fiction
