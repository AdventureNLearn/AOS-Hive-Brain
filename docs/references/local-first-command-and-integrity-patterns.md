## Patterns worth carrying forward (principle level)

### 1. Command Nexus interaction model
- Global command palette (keyboard-first: Ctrl/Cmd+K or `/`)
- Number-key cockpit for primary views (1–5 style)
- Time-window queries and a forensic “time machine” for reviewing sealed events
- Living central visualization (fabric / map / graph) that stays calm rather than theatrical

**Hive Brain alignment:** Supports the “Orient” and “Integrity” rooms and the decision-playback scrubber. Prefer keyboard-complete, progressive-disclosure surfaces over dense dashboards.

### 2. Local-first purity as a quality floor
- Brain and durable data stay on the operator’s machine by default
- No forced cloud path for core function
- Explicit, optional edge or tunnel only when the operator chooses it
- Sidecar metadata preferred over polluting source files

**Hive Brain alignment:** Matches the public OPSEC posture and the “someone else can continue” rule. Public demos should never require private credentials or remote state to be useful.

### 3. Integrity sealing (Merkle-class)
- Incidents or important claims can be sealed with a portable manifest
- Offline replay of a sealed record is possible
- Verification is a first-class, auditable action
- Sealing is explicit and human-triggered, not automatic truth

**Hive Brain alignment:** Directly supports Supported / Unproven / Disputed labeling and the recorded Human Decision event. Prefer honest incomplete seals over confident fiction.

### 4. Adaptive / morphing modules (principle only)
- Personas or presentation layers can change under clear rules
- Multi-objective scoring can rank alternatives without declaring a winner
- Evolution is driven by observable fitness, not by popularity metrics

**Hive Brain alignment:** Useful for progressive disclosure and for keeping the integrity kernel separate from any adaptive presentation. Never treat model agreement or genome score as automatic truth.

### 5. Progressive power with safety rails
- Wizard-style onboarding for complex capability (profiles, quiet hours, reduced aggression)
- Kid / quiet modes that lower noise without removing the tool
- PWA install path so the surface can feel native while remaining local-first

**Hive Brain alignment:** Makes powerful reasoning shapes approachable to a high-school senior and a senior engineer at the same time. Prefer additive modes over overwriting existing shapes.

### 6. Calm scientific visual language
- Soft adaptive surfaces, crystalline precision, reduced-motion support
- Optional 3D / WebGL with graceful 2D fallback
- Efficacy or status gauges that report local computation, not marketing numbers

**Hive Brain alignment:** Matches the existing Three.js Hive scene and the preference for museum-like clarity over game-like spectacle.
